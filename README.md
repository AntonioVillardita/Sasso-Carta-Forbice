# Gioco Sasso Carta Forbice

## Descrizione

Il famoso gioco più antico.  
Quì ho deciso di dare la scelta da prendere attraverso i 3 rispettivi tasti, dove sotto ad essi è presente un display che mostra il risultato.  
Per renderlo più chiaro, ho scelto di mostrare oltre al risultato anche entrambe le scelte, sia del giocatore che della CPU in modo da spiegare il perchè di quel risultato.  
In parte fatto con IA.
